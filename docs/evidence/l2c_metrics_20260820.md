## 같은 시나리오의 수정 전후

깨끗한 기준 커밋의 5개 사이트 자율탐색은 `0/5`였다. 상세 정제 출력이 잘려
스키마 파싱에 실패한 실행 1개와 수집 결과가 0건인 실행 4개였다. 출력 상한,
아이콘 클릭 제한, 누적 무변화 강제 종료, 스크롤 입력, 묶음 입력 뒤 OCR 전환을
수정한 작업 트리에서는 자동 계약 `5/5`, 사람 판정 `4/5`가 됐다.

이 비교는 같은 검색어와 사이트 행렬로 회귀를 복구한 기록이다. 수정 결과가 아직
깨끗한 커밋에서 재실행되지 않았고 로켓펀치 의미 실패가 남았으므로 최종 안정성
수치로 사용하지 않는다.

1. **2026-08-20 기준 5개 사이트 스모크 테스트는 자동 완료 5/5, 실제 공고까지 확인한 수집 성공

   86.7%, 네 필드 모두 통과 80%를 기록했다.** 실패가 고용24 접힌 본문에
   집중된다는 개선 지점까지 특정했다.
3. **2026-08-20 기준 원티드 경험 경로 한 건이 같은 공고를 유지하면서 추론 2회를 대체하고

   성과로 사용했다.
4. **2026-08-20 기준 한 건 수집의 평균은 51.26초, 58,476토큰, 약 $0.047이다.** 시간·토큰·
