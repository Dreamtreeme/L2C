# 원티드 채용공고 수집

원티드 홈에서 보이는 검색 UI를 사용하십시오. `/search?query=...` 주소를 직접 만들지 마십시오.

검색 결과에서는 사용자 검색어와 직무명 또는 핵심 기술이 직접 일치하는 공고를 우선합니다. 인접 직무가 섞였고 화면에 적절한 필터가 있으면 먼저 적용하며, 단지 관련 있다는 이유로 목표 수를 채우지 마십시오.

공고 카드는 보이는 직무명과 회사명으로 식별하고 직무명을 `target_label`에 보존하십시오. 보상금, 태그, 배지, 일반 아이콘을 카드 식별자로 사용하지 마십시오.

검색·상세 펼침·스크롤·뒤로가기는 안정적인 재생 후보입니다. 공고명과 카드 순서는 실행마다 달라지므로 현재 화면의 미방문 공고 선택은 모델이 판단합니다.
